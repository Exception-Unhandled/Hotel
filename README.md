# Hotel
This was a project I made in 2025 with a friend. <br>
It features a reservation manager of a hotel, allowing the user to import reservations through a .txt file, insert a new one, search, show filled, edit, export, generate, number the available room slots, check room prices and clear a reservation. <br><br>
> **WARNING**: This project has bugs and is poorly organized. At the time I had no idea how to organize a project.

<br>Still, if you *are* interested on taking a look on my first project using github, feel free to explore. <br>
The original project was made in portuguese, the english version is available on the 'english_ver' branch.
This project uses .NET 8.0
